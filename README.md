# TicketRail

Kubernetes 기반 열차 예매 서비스 인프라 구축 및 하이브리드 클라우드 확장 프로젝트

## 프로젝트 개요

대규모 동시 접속과 장애 상황에 대응하기 위한 Kubernetes 기반 열차 예매 서비스를 구축하고, Hybrid Cloud 및 Full AWS 환경으로 확장하여 성능과 가용성을 검증한 팀 프로젝트입니다.

## 프로젝트 구성

- **1차 프로젝트:** 온프레미스 Kubernetes 기반 고가용성 인프라 구축
- **2차 프로젝트:** Hybrid Cloud 및 Full AWS 환경 확장 및 성능 검증

## 주요 기능

- 사용자 대기열 및 입장 제어
- 열차 조회 및 좌석 선점
- 티켓 예매 및 결제 처리
- 예매 완료 및 알림 처리

## 상세 포트폴리오

프로젝트 아키텍처, 개인 담당 업무, 인프라 설계 및 구축 과정, 트러블슈팅, 성능 검증 결과는 Notion 포트폴리오에서 확인할 수 있습니다.

- Notion 포트폴리오 (링크 추가 예정)

## 참고 사항
